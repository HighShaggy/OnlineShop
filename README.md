Это полноценный онлайн-магазин игровых аксессуаров (мыши, клавиатуры, наушники и др.), разработанный на ASP.NET 7 с использованием MVC-архитектуры и современных веб-технологий.

🛠 Технологии и ключевые особенности

🔹 Основной стек

ASP.NET 7 + MVC
Entity Framework Core (работа с MySQL)
Dependency Injection и Чистая архитектура
Автомаппинг (кастомный через рефлексию)
LINQ для работы с данными
Миграции БД

🔹 Аутентификация и безопасность

ASP.NET Core Identity (регистрация, вход, роли)
Claims-based-авторизация

🔹 Frontend и UX

Модальные окна (просмотр товаров, корзина)
Частичные представления и View Components
Figma (дизайн и прототипирование)

🔹 Дополнительные функции

Работа с файловой системой (загрузка изображений)
Логирование действий системы
🚀 Запуск проекта

Клонировать репозиторий
Настроить подключение к MySQL
Применить миграции (dotnet ef database update)
Запустить через dotnet run
